# About:
This application helps in transforming rude/aggressive sentences into a professional format. In a hectic lifestyle we might unknowingly send messages to important people in a rude tone. Here is your companion to help you during those times.

# To run frontend:
npm start

# To run backend:
uvicorn main:app --reload

# Important:
Add your own api key in .env file and make required changes in nlp_engine.py
(specifiying the right model)
